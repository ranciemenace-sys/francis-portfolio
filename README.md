# Francis Kameta — Personal Portfolio

Welcome to my personal portfolio website. This project showcases my skills, projects, services, and development journey as an IT student interested in technology and cybersecurity.

## 🌐 Live Website

**Portfolio:** https://francis-kameta-portfolio.vercel.app

## 📂 GitHub Repository

**Repository:** https://github.com/ranciemenace-sys/francis-portfolio

---

## 📖 About the Project

This portfolio website was developed as part of my Web Technologies and Internet Applications coursework at KCA University.

The website is designed to provide an overview of my technical skills, projects, services, and contact information while demonstrating my understanding of modern web development concepts.

The portfolio uses semantic HTML, CSS for styling and responsive design, and JavaScript to add interactive functionality.

It also connects to the GitHub API to dynamically display my public GitHub repositories.

---

## ✨ Features

### 🏠 Home Page

* Personal introduction
* Profile information
* Navigation to the different sections of the portfolio
* Responsive layout

### 💻 Projects

The projects section showcases my current and planned projects, including:

* **TutorMe** — A platform designed to connect students with tutors according to their learning needs and preferred pace.
* **HouseMe** — A home-finding platform designed to help users find homes based on their preferences, location, and budget.
* **Cybersecurity Home Lab** — A cybersecurity practice environment using an Ubuntu server and Kali Linux machine connected on the same network.

### 🛠️ Skills

The portfolio demonstrates my current skills and proficiency levels in:

* HTML
* CSS
* Python
* Networking
* Database Management

Visual progress indicators are used to represent my current proficiency levels.

### 🔎 Project Filtering

JavaScript is used to filter projects by category:

* All
* Web Development
* Cyber Security

### 🐙 GitHub API Integration

The Projects page connects to the GitHub REST API to retrieve and display public repositories from my GitHub profile.

The GitHub section dynamically displays information such as:

* Repository name
* Repository description
* Primary programming language
* Stars
* Forks
* Link to the GitHub repository

The page also includes loading and error handling for the API request.

### 📩 Contact Form

The portfolio includes a contact form with client-side JavaScript validation to check user input before submission.

### 📱 Responsive Design

The website is designed to work across different screen sizes, including:

* Desktop
* Tablet
* Mobile devices

## 🚀 Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/ranciemenace-sys/francis-portfolio.git
```

### 2. Open the project

Navigate into the project directory:

```bash
cd francis-portfolio
```

### 3. Open the website

Open `index.html` in a web browser.

Alternatively, use the Live Server extension in Visual Studio Code for a better development experience.

## 🔌 GitHub API

The portfolio uses the GitHub REST API to retrieve public repositories.

The API endpoint used is:

```text
https://api.github.com/users/ranciemenace-sys/repos
```

JavaScript fetches the repository data and dynamically creates project cards on the Projects page.

This demonstrates the use of:

* Fetch API
* Promises
* JSON data
* Array iteration
* DOM manipulation
* Error handling
* Dynamic HTML generation
